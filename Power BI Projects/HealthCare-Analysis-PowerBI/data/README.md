# Dataset Files

The `data` folder contains the CSV source files used in the Healthcare Analysis Power BI project.

| File | Description |
|---|---|
| `visits.csv` | Visit-level financial, service, admission, insurance, and satisfaction data |
| `patients.csv` | Patient demographic information |
| `providers.csv` | Provider information |
| `cities.csv` | City and state lookup |
| `department.csv` | Department lookup |
| `diagnose.csv` | Diagnosis lookup |
| `procedures.csv` | Procedure lookup |
| `insurance.csv` | Insurance provider lookup |

The source data is included so the transformation and modeling workflow can be inspected alongside the PBIX file.
