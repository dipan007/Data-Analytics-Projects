# Images

Add the selected project screenshots using these filenames:

- `Hero.png`
- `Entry_Form.png`
- `Transaction_Entry.png`
- `Master_Database.png`
- `Macro_Automation.png`
- `Dashboard.png`

## Recommended Screenshot Sources

### Hero.png
Use a strong overall view of the tracker, preferably the dashboard or a clean view showing the system's main output.

### Entry_Form.png
Show the controlled sales-entry form with the validation fields visible.

### Transaction_Entry.png
Show the example transaction before submission, preferably with Sales Officer, Product, Region and Value visible.

### Master_Database.png
Show the master sales records with the newly inserted transaction visible.

### Macro_Automation.png
Use the strongest available visual proof of the Submit → Macro → Database process. If no suitable screenshot exists, create a new one from the live tracker.

### Dashboard.png
Show the live dashboard after the transaction has been processed.

## Screenshot Guidelines

- Crop tightly around the useful content.
- Keep headers and important labels readable.
- Avoid unnecessary browser or desktop UI.
- Do not use several nearly identical screenshots.
- Prefer real tracker screenshots over screenshots of the presentation whenever possible.
